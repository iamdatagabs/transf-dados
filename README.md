# Transformação de Dados

Repositório de exercícios e exemplos relacionados à transformação e preparação de dados.

## Contexto
A transformação de dados é uma etapa central de pipelines analíticos: padronização de formatos, limpeza, conversão de tipos, tratamento de valores ausentes e organização para análise.

Este README descreve o tema geral do repositório. Consulte os arquivos disponíveis para identificar as operações e ferramentas efetivamente implementadas.
